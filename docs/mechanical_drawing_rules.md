# AI CAD Copilot 机械制图可编码规则

版本：2026-09-01  
默认体系：GB/T，第一角投影，尺寸单位 mm

## 1. 范围与来源

本文件不是标准原文，也不替代标准购买、企业规范或设计审批。它只把当前产品需要的机械图表达原则整理成可执行规则。国家标准状态以国家标准全文公开系统为准；截至本报告日期，下列项目页面均标记为“现行”：

FreeCAD 实现依据包括官方 `DrawViewDimension`、`DrawViewPart` API；所有制造尺寸必须由 `References2D/References3D` 关联真实投影几何，而不是 Annotation 或 SVG 文本。

## 2. 决策层与布局层

`MechanicalDrawingRuleEngine` 决定“画什么”：视图、剖视、中心线、尺寸、公差、表面要求及其理由。

`DrawingLayoutEngine` 决定“放哪里”：图幅、标准比例、视图坐标、尺寸层级、说明区域、碰撞和边界修正。

禁止把零件类型判断或制造尺寸选择写成布局坐标分支。

## 3. 视图选择

### 3.1 最少且充分

1. 选择最能表达形状、加工位置或工作状态的方向为主视图。
2. 只增加为消除歧义所必需的基本视图、向视图、局部视图、剖视或断面。
3. 每个视图必须记录 `why_this_view_exists`。
4. 若一个主视图已完整表达零件，不增加装饰性视图。
5. 轴测图只用于复杂空间结构的辅助理解、用户明确要求或空间充足的说明用途；不得承载主要制造尺寸。

### 3.2 第一角投影

项目默认 `projection_method=first_angle`。相邻基本视图保持真实投影对应：对应中心线对齐，视图位于第一角投影规定的相对方向。若因版面需要移开，则必须转为带视向箭头和字母的向视图；不能把无标识端视图放在任意空白处。

当前布局编码关系：

- 轴类端视图：位于主视图左侧并水平中心对齐。
- 板类厚度视图：位于主视图下方并垂直中心对齐。
- 任一基本视图偏离上述关系，`projection_consistent=false`。

### 3.3 剖视与断面

- 内部孔、腔、槽仅靠隐藏线无法清楚表达时选择剖视。
- 只需表达某处横截面轮廓时优先断面，避免增加完整剖视。
- 剖切位置、方向、标识和剖面线必须成为模型中的可检查对象。
- 已由外形和端视图完整表达的简单通孔法兰，不自动增加剖视；有台阶孔、沉孔或内部腔时再增加。

## 4. 零件表达策略

### 4.1 阶梯轴

- 主视图：轴线水平，表达轴段、肩部、倒角、圆角和轴向长度。
- 端视图：表达圆截面以及键槽等圆周特征；置于主视图左侧。
- 中心线：主视图完整轴线；端视图水平、垂直中心线及圆心标记。
- 默认不加轴测图。
- 尺寸：直径、总长、以制造基准确定的肩位、键槽、C、R；避免轴向闭合尺寸链。

### 4.2 法兰

- 圆面主视图：外径、内孔、孔阵列、孔径、孔数和分度圆。
- 轴向侧视图：厚度和台阶。
- 圆和孔阵列生成中心线/中心标记。
- 有内部台阶、沉孔或密封槽且基本视图不能表达时增加剖视。

### 4.3 带孔板

- 面视图：外形、孔径和孔坐标。
- 厚度视图：只在厚度不能由面视图表达时增加，置于主视图下方。
- 孔定位从选定基准边或对称中心标注，不同时重复链式和坐标式位置。

### 4.4 螺栓

- 主视图：公称直径、长度、螺纹有效长度、头部高度和倒角。
- 端视图：六角头对边尺寸。
- 工程图采用规范简化螺纹表示和 `M10×1.5` 等代号；模型可以使用螺旋特征，但正式图不以完整螺旋线作为主要表达。

## 5. 图线与中心要素

- 可见轮廓：粗实线。
- 不可见轮廓：需要且不致使图样混乱时用细虚线；优先用剖视消除大量隐藏线。
- 中心线/轴线：细点画线，适当超出轮廓；回转体、圆、孔、同心圆必须有对应中心要素。
- 尺寸线、尺寸界线、引出线：细实线；箭头、文字和界线不能与轮廓、标题栏或其他尺寸文字相撞。
- `line_types_valid` 必须由真实 TechDraw 属性或中心线对象验证，不能只由计划声明。

## 6. 尺寸标注

### 6.1 总则

1. 每一制造尺寸只定义一次。
2. 优先以设计/加工/检验基准组织尺寸。
3. 不把所有可测几何自动全部标出。
4. 避免封闭尺寸链；保留一个由一般公差或工艺控制的非闭合环节。
5. 尺寸尽量标在表达该特征最清楚的视图上。
6. 局部尺寸靠近轮廓，分段/基准尺寸在外层，总体尺寸位于最外层。

### 6.2 阶梯轴轴向尺寸算法

当前策略选择：总长 + 从左侧统一基准到每个肩位的坐标尺寸。它替代旧的 `300 + 150 + 2×75` 闭合/重复链。对于 300 mm、75/150/75 三段轴，输出 `300、75、225`，不再同时输出 `150` 和 `2×75`。

### 6.3 符号

- 直径：`⌀`/`Φ` 前缀，并关联圆或两条对应母线。
- 半径：`R` 前缀，引出线箭头指向真实圆弧。
- 倒角：使用 `C` 或“长度×角度”表达；当前 `C1` 必须关联真实 Chamfer 投影边，不允许文本冒充。
- 螺纹：公称代号、螺距、公差带、旋向等按真实设计输入输出；无来源不补写。

## 7. 公差、配合与表面要求

### 7.1 来源等级

系统只允许以下来源进入正式图：

- `user`：用户明确要求。
- `design_engine` / `functional_requirement`：由载荷、配合、功能链计算或判定，并有理由。
- `standard`：明确引用标准表项。

`assumption` 只能进入报告的 `RECOMMENDED`，不能变成图纸硬性要求。

因此：

- 没有功能依据时不自动加 `Φ40 h6`。
- 没有尺寸链或一般公差来源时不自动加 `300 ±0.2` 或 `GB/T 1804-m`。
- 模板默认 `Ra 3.2` 已删除。只有加工方法与功能表面确定后才能作为 `REQUIRED`；推测只能列为 `RECOMMENDED`，且不写入正式制造要求。

## 8. 比例、图幅和标题栏

- 比例只能从配置的标准系列选取：`2:1、1:1、1:2、1:2.5、1:5、1:10`。
- 先保护主视图，再容纳必要辅助视图和尺寸；A4 不足时降低标准比例，仍不足再升级 A3。
- 禁止输出 `1:2.85714` 等任意比例。
- 所有视图、尺寸和文字必须位于安全绘图区，标题栏和说明区为禁入区域。
- 标题栏至少包含名称/图号、材料、比例、投影/采用标准、创建者和状态；未指定的一般公差保持空白，不得伪造。

## 9. 制造完整性验证

验证器分为五个门：

1. `geometry_layout`：边界、标准比例、碰撞、标题栏隔离。
2. `mechanical_representation`：投影一致、中心线、最少且充分视图、轴测/剖视理由、图线和标准声明。
3. `dimensioning`：尺寸齐全、无重复、无闭合链、真实关联。
4. `tolerancing`：功能公差均有来源；没有来源时不得凭空添加。
5. `manufacturing_completeness`：材料、标题栏和该零件策略要求的制造尺寸齐全。

任一门为 FAIL，均不得报告 `Mechanical drawing validated = PASS`。

## 10. 视觉闭环

工程图流程固定为：Generate → get_view/截图 → Mechanical Drawing Review → 有限次纠正 → 再截图 → Validator。视觉审查需要回答：每个视图为何存在、投影是否一致、中心线是否完整、尺寸是否重复、公差是否有依据、制造信息是否充分、是否存在无意义内容。截图不能替代结构化验证，两者必须同时通过。

## 11. 当前边界

- 本规则库不宣称覆盖标准的全部条款。
- 几何公差、焊接符号、齿轮/花键、完整表面纹理符号和复杂剖切尚需专门规则模块。
- 企业图框、企业一般公差和工艺路线必须由项目配置输入，不能由 Agent 猜测。

## 12. 已编码并实测的关键规则

- 中心线不再使用会把坐标轴颜色导出到 PDF 的旧 `HorizCenterLine` / `VertCenterLine` 开关。系统在投影完成后创建真实 TechDraw CenterLine，设置黑色、0.18 mm、点划线和 3 mm 轮廓外延，并由 Validator 读取格式记录。
- 法兰 PCD 不能通过两个孔圆边直接量取，否则 TechDraw 得到的是切边净距 `PCD-hole_diameter`。系统从当前参数化孔阵列中心重建 TechDraw 节圆构造线，再用 `DrawViewDimension` 关联节圆直径。
- 对称带孔板采用总长/总宽、孔径、水平和垂直孔中心距表达，避免把孔圆切边距离误报为孔中心的基准边距离；本次 120×80 板的中心距为 84×44。
- `line_types_valid`、`associative_dimensions`、`required_dimensions_present`、实测值和无 `0.63` 异常均来自当前 FreeCAD Document 内对象，不由期望字符串代替。
